## 프로젝트 목록

- **GunfightKingExcelConverter**는 실제 서비스 일정과 기획 조직의 요구에 맞춰 "지금 당장 필요한 자동화"를 빠르게 만들고 다듬어 온 툴입니다. 기획자가 매번 반복하던 Excel → JSON 변환 작업을 없애고, 데이터 오류를 빌드 이후가 아니라 변환 시점에 잡아내도록 만든 실무 경험을 보여줍니다.
- **StageMaker**는 시간 제약 없이 처음부터 레이어(Model / Service / Control)를 분리하고, WPF 커스텀 컨트롤을 상속 구조로 재사용 가능하게 설계하는 데 집중한 프로젝트입니다. 실무에서는 속도 때문에 타협했을 법한 구조적 완성도를 어떻게 끌어올리는지를 보여주기 위한 목적입니다.

두 프로젝트를 같이 보면 "빠르게 동작하는 툴을 만드는 능력"과 "유지보수 가능한 구조로 설계하는 능력"을 함께 확인하실 수 있습니다. 각 프로젝트의 자세한 처리 흐름과 코드는 폴더 하위 README에서 확인하실 수 있습니다.
